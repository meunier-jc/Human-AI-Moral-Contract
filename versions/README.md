## Historical note on the v2.7 date

A previous version of this index dated v2.7 as "March 2026" and described it as the current stable version. Two corrections apply as of October 20, 2026:

1. **Date.** The metadata of the v2.7 file itself states February 25, 2026 (header, internal changelog, conclusion) and prevails under the author's dating rule. Some successor files (v2.9, v3.6) cite v2.7 as January 26, 2026 in their lineage lines; the concerned file's own metadata is authoritative.
2. **Status.** v2.7 is not current. This repository is archived; the framework continues as CIP v5.2 in [authentic-fluency](https://github.com/meunier-jc/authentic-fluency).
